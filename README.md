# 🏗️ BuildTrack  
### Construction Management System

BuildTrack is a **web-based Construction Management System** designed to streamline project planning, resource management, attendance tracking, and reporting for construction companies.  
The system aims to replace manual processes with a centralized, efficient, and transparent digital solution.

This project was developed as part of the **M.Sc. (CA & IT)** curriculum in collaboration with **Bhagwati Infrastructure**.

---

## 📌 Project Overview

Construction projects often face challenges such as:
- Manual data handling
- Poor communication between stakeholders
- Difficulty in tracking attendance, inventory, and project progress
- Time-consuming cost estimation and reporting

**BuildTrack** addresses these problems by providing a role-based system that enables better coordination, automation, and monitoring of construction activities.

---

## 🎯 Objectives

- Digitize construction project management
- Provide secure authentication and role-based access
- Track project progress and site activities efficiently
- cost estimation, and reports
- Improve communication between admin, members, and clients
- Reduce manual work and operational errors

---

## 👥 Stakeholders & Roles

### 🔑 Admin
- Manage users and roles  
- Create and manage projects  
- Track project progress 
- View attendance and generate reports  

### 👷 Member
- Mark attendance  
- View assigned tasks  
- Submit site reports  
- Track project progress  

### 👤 Client / User
- View project details and progress  
- Access reports  
- Submit feedback  
- Make service or rental inquiries
